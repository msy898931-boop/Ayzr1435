# Ayzr1435 — MarketDesk Bot

بوت تلغرام لمكتب تحليل الذهب (XAUUSD) — `@Ayzr1324_bot`.

نسخة احتياطية من الكود الكامل، **بلا أي أسرار** (التوكن غير موجود في هذا المستودع).

## الملفات

| الملف | الوصف |
|---|---|
| `bot.py` | **المحرك** — المصدر الوحيد للمنطق (القرار، التسعير، التقييم، البطاقات) ودالة التشغيل الواحدة `start_desk()`. |
| `app.py` | **غلاف Render** — خدمة ويب مجانية بتخدم `/health` وبتشغّل نفس المحرك. هي اللي شغّالة على الإنتاج. |
| `keepalive.py` | سكربت إبقاء الخدمة صاحية (لو استعملت VPS أو Cron بدل self-ping). |
| `automation/main.py` | **هدف مجدول منفصل** — نسخة مستقلة للـ OpenHands Automation (حالتها بـ KV). نسخة قديمة؛ أي قاعدة جديدة لازم تنضاف بـ `bot.py` أولاً. |
| `flybot/` | حزمة النشر على Fly.io. **ما فيها نسخة من البوت**: `deploy.sh` بينسخ `bot.py` وقت البناء. |
| `run-bot.sh` | سكربت إعادة تشغيل تلقائي للبوت الدائم. |
| `tests/` | اختبارات `unittest` للمحرك (بلا شبكة). |

> **قاعدة المشروع:** محرك واحد (`bot.py`)، نقاط دخول كثيرة. أي منطق قرار يُكتب مرة واحدة — `start_desk()` هي المكان الوحيد اللي تُعدّ فيه خيوط البوت، فلا تقدر نقطة دخول تنسى خيطاً وتشغّل بوتاً مختلفاً.

## التشغيل

البوت بياخد التوكن من متغيّر بيئة `TG_TOKEN` (أو `TELEGRAM_BOT_TOKEN`، أو ملف `.tg_token`).

```bash
# البوت الدائم (VPS/جهاز) — poller + desk + backup
TG_TOKEN=<توكنك> python3 bot.py

# غلاف Render (خدمة ويب + self-ping) — نفس المحرك
PORT=10000 TG_TOKEN=<توكنك> python3 app.py

# دورة وحدة (زي ما بتعمل الأتمتة المجدولة)
TG_TOKEN=<توكنك> python3 automation/main.py
```
