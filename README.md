# Ayzr1435 — MarketDesk Bot

بوت تلغرام لمكتب تحليل الذهب (XAUUSD) — `@Ayzr1324_bot`.

نسخة احتياطية من الكود الكامل، **بلا أي أسرار** (التوكن غير موجود في هذا المستودع).

## الملفات

| الملف | الوصف |
|---|---|
| `automation/main.py` | **البوت المجدول** — النسخة اللي بتشتغل على OpenHands Automation. بتصحى كل دقيقة، بتسمع 40 ثانية، بتردّ، وبتسكّر. |
| `bot.py` | **البوت الدائم** — long-polling مستمر (لو بدك تشغّلو على VPS/جهاز). |
| `flybot/` | حزمة النشر على Fly.io (Dockerfile + fly.toml + deploy.sh + run.sh). |
| `run-bot.sh` | سكربت إعادة تشغيل تلقائي للبوت الدائم. |
| `main.py`, `desk-monitor.py` | نسخ أقدم (متابعة صفقة). |

## التشغيل

البوت بياخد التوكن من متغيّر بيئة `TG_TOKEN` (أو `TELEGRAM_BOT_TOKEN`، أو ملف `.tg_token`).

```bash
# البوت الدائم
TG_TOKEN=<توكنك> python3 bot.py

# دورة وحدة (زي ما بتعمل الأتمتة)
TG_TOKEN=<توكنك> python3 automation/main.py
```

## المزايا

- 📊 تحليل السوق (اتجاه على 6 فريمات)
- 🎯 توصية بوقف وهدف و R:R (بترفض أي صفقة R:R أقل من 1.5)
- 🎬 سيناريوهات مشروطة + 🔔 مستويات
- 📒 سجل صفقات (يومي/أسبوعي/شهري) — تقييم بالـR مو بالنقاط
- 🔭 متابعة الصفقات المفتوحة + تنبيه لما تنحسم

> قراءة تحليلية، مو وعد ربح.
