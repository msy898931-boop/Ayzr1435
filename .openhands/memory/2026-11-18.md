# MarketDesk — 2026-11-18

## FX-AI Quant teardown (competitor reference build)

Owner asked for a full, read-only teardown of
`https://forex-consensus-production.up.railway.app/` ("FX-AI Quant") so we can
build one like it. Report: **`FXAI_REFERENCE.md`** in the Ayzr1435 repo root
(committed — the workspace is ephemeral). Assets cached in `/tmp/fxai/`.

### Method (read-only, "don't harm anything")
GET on every public asset + API; POST with **dummy** values only, to learn the
response shape of the VIP/admin routes. Nothing written on their side: no trade,
no key generated, no payment, no delete. The one `submit-payment` POST used an
all-zero TxID (accepted — which is itself the finding: no TxID verification).

### What it is
- SPA: `index.html` 100KB/1510 lines, `app.js?v=3.7` 90KB/2070 lines (41
  functions, 188 DOM ids, 25 listeners), `style.css` 3.7KB. Tailwind via CDN,
  Font Awesome, Cairo, TradingView `tv.js`. Backend Express on Railway
  (`server: railway-hikari`). 12 API routes, all CORS `*`.
- Layout: header (sessions clock, visitor counter, VIP button) → ticker tape →
  VIP banners → live bot-trade radar → pair/timeframe bar + 1H candle countdown
  → strength meter (XAU/DXY) + US10Y macro + SMT gold/silver + news radar →
  MTF matrix (15m/1H/4H/1D) + liquidity pools (PDH/PDL/Asian) → TradingView
  chart + 6 indicator cards + candlestick patterns + SMC card → AI decision
  card + execution plan + lot calculator + reasons → deep AI report → verified
  track record table → footer; VIP modal, admin modal, Gemini modal, TG widget.

### The findings that matter for our build
1. **Paywall is presentation, not server-side.** Free `/api/analyze` ships the
   whole math (RSI/MACD/EMA/BB/ATR/pivots/fib) AND leaks the direction:
   `signal:"VIP_LOCKED"` next to `signalArabic:"بيع (Sell)"` + `signalClass:"sell"`,
   and `smc.lastSwingHigh/Low` while `smc.structure` says "🔒 محجوب".
2. **Track record is inflated.** Panel: 19 trades / 84% / +1120 pts. From their
   own `recentTrades` (exit−entry): **−353 pts**. Every "profit secured" close is
   stamped **+50 "BE"** regardless of exit (a −31-pt sell shows +50 🛡️); a
   `today-tp2` with no entry/exit counts +380.
3. **Bugs, measured:** `timeframe` ignored (5m=30m=1h=1w identical); GBPUSD
   returns gold's price with GBP indicators + `tvSymbol:"OANDA:XAUUSD"`;
   `timeframe=abc`→200, unknown symbol→500; lot calculator `$10/pip for gold`
   (gold is **$100/pip** — 10× off); "26 indicators/TF" is 4 fields/TF.
4. **Security:** VIP key 10 years in cookie+localStorage+URL; `?dev=<secret>`
   backdoor auto-grants the owner key; no server session; admin secret is a body
   field on CORS-`*` routes; no CSP/HSTS; TxID unverified.

### What we take / what we refuse
- Take: the single-page layout idea (it already mirrors our map+cards), the
  candle countdown, session clock, macro/SMT panels, MTF matrix, a lot
  calculator — **with correct math** (we have `POINT_VALUE`/`account.py`).
- Refuse: URL/cookie VIP key, `?dev=` backdoor, UI-only masking, "BE = +50",
  CORS `*`, unverified payments.
- Gap vs us: we already have `bot.py` engine + `app.py` + `map.html`; the real
  work is **one web page that gathers all our existing views** — build it from
  `app.py`, not from scratch.
